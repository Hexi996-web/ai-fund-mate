# 主题证据中文化设计

## 目标

修复主题详情中的字面量 `` `n ``，将五类证据的内部英文规则、指标代码和缺失状态转换为可读中文，并将“降级与缺失”升级为“数据缺口与可信度说明”。

## 方案

新增独立前端解释模块，集中维护指标名称、规则文案、错误状态和影响说明的映射。底层 `scores.json`、评分算法和历史快照保持不变，原始代码仍可追溯但不直接展示给用户。

无法识别的规则或缺口必须使用中文兜底文案，不得把内部英文代码直接展示到页面。缺口说明包含指标名称、原因与对研判的影响。五类证据中的规则文案和证据条目在渲染前统一本地化。

## 验收

- 页面源码和渲染结果不出现字面量 `` `n ``。
- 页面不显示 `source_unavailable`、`parse_failed`、`no current observation` 等技术文本。
- 板块名称为“数据缺口与可信度说明”。
- 五类证据规则均为中文，未知输入有中文兜底。
- 单元测试、浏览器测试和生产构建通过。
